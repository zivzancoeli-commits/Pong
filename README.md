# Pong

## What it has
It's really basic but it has :
1. A basic up and down movement system
2. Score count
3. An awesome background (didn't I do a great job)
4. A death screen
5. Way to many variables

## How to play
1. Open https://zivzancoeli-commits.github.io/Pong/
2. Click "Start"
3. Use W and S or up and down arrow to move your pong up and down to block the moving ball
4. The more you block it the higher score you get but if it goes by then you lose :(
5. Get lots of points

## How to cheat
1. Open https://zivzancoeli-commits.github.io/Pong/
2. Open the the console using F12
3. Type (or paste) "score = [Insert score here];"
4. Then move to make it look like you earned it
